Local Data Storage / 本地数据存储

All data generated by the app -- including your savings challenges, check-in records, settings, and preferences -- is stored exclusively on your device using local JSON files.

本应用生成的所有数据 -- 包括您的存钱挑战、打卡记录、设置和偏好 -- 均仅存储在您设备的本地，使用 JSON 文件格式保存。

What is stored locally / 本地存储的内容：

  • Savings challenge configurations (challenge type, start date, amounts, increment values) / 存钱挑战配置（挑战类型、开始日期、金额、递增值）
  • Check-in history records (dates and amounts saved) / 打卡历史记录（日期和存钱金额）
  • App settings and user preferences (reminder times, theme settings) / 应用设置和用户偏好（提醒时间、主题设置）

How data is stored / 数据存储方式：

  • All data is saved as plain JSON files within the app's sandboxed container on your device
  • All data is saved as plain JSON files within the app's sandboxed container on your device
  • 数据以纯 JSON 文件格式保存在您设备上应用的沙盒容器内
  • Data is never transmitted over the internet or to any external server
  • 数据永远不会通过互联网传输或发送到任何外部服务器

Deleting your data / 删除您的数据：

You can delete all app data at any time by deleting the app from your device. All JSON files and stored data will be permanently removed.

您可以随时通过从设备中删除本应用来删除所有应用数据。所有 JSON 文件和存储的数据将被永久删除。

The app does not make any network requests. It does not use Wi-Fi, cellular data, or any form of network connectivity. The app functions fully offline.

本应用不发起任何网络请求。不使用 Wi-Fi、蜂窝数据或任何形式的网络连接。本应用在完全离线状态下正常运行。

  • No data is sent or received over the internet / 不通过互联网发送或接收数据
  • No cloud sync or backup services / 无云同步或备份服务
  • No crash reporting or analytics services / 无崩溃报告或分析服务
  • No remote configuration / 无远程配置

Third-Party Services / 第三方服务

The app does not integrate with any third-party SDKs, services, or libraries that collect or transmit user data. There are no advertising networks, analytics providers, or social media integrations.

本应用不集成任何收集或传输用户数据的第三方 SDK、服务或库。没有广告网络、分析提供商或社交媒体集成。

Children's Privacy / 儿童隐私

SaveTheChange is rated 4+ and is suitable for users of all ages, including children.

存钱挑战的应用分级为 4+，适合所有年龄段的用户，包括儿童。

We do not knowingly collect any personal information from children. Because the app does not collect any personal information from any user -- regardless of age -- children's data is treated the same as all other users' data: it is stored locally on the device and is never transmitted or shared.

我们不会故意收集儿童的任何个人信息。由于本应用不收集任何用户的个人信息 -- 无论年龄 -- 儿童的数据与所有其他用户的数据处理方式相同：仅存储在设备本地，永远不会被传输或共享。

Parental Guidance / 家长指引：

The app is designed to help users of all ages develop healthy savings habits. Parents may wish to:

  • Help younger children set up age-appropriate savings challenges / 帮助年幼的孩子设置适合年龄的存钱挑战
  • Review the app together with their children to understand how savings tracking works / 与孩子一起查看应用，了解存钱追踪的工作原理
  • Use the app as a tool to teach children about money management / 将应用作为教授孩子理财的工具
